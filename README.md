# Shazycool — Landing Page

Official one-page landing site for **Shazycool**, Afro artist.
Goals: **streams** + **bookings**.

Live: https://shazycool.com

## Stack
- Plain HTML / CSS / JS — no build step
- Hosted free on GitHub Pages
- Forms via Formspree
- Custom domain + email via Cloudflare DNS + Zoho Mail

## Local preview
Just open `index.html` in a browser.

Or run a local server:
```bash
python3 -m http.server 8000
